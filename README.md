# Онлайн-викторина

Многопользовательская викторина в реальном времени на Node.js + Socket.IO.

## Установка

npm install

## Запуск

npm start
# или для разработки:
npm run dev

Открой http://localhost:3000

## Как играть

1. Введи имя и нажми «Создать комнату» — получишь 5-значный код.
2. Друзья открывают сайт, вводят имя + код → попадают в лобби.
3. Создатель жмёт «Начать игру».
4. У всех одновременно появляется вопрос с таймером.
5. За правильный ответ даётся до 1000 очков (зависит от скорости).
   Серия из 3+ правильных подряд — бонус ×1.2.
6. После каждого вопроса — таблица лидеров.
7. В конце — финальный рейтинг и кнопка «Играть снова».

## Технологии

- Node.js + Express
- Socket.IO (WebSocket + auto-reconnect)
- Vanilla JS + CSS
